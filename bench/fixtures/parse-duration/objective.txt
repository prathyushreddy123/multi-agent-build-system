Add parseDuration(text) to a new file src/parse.js as the inverse of formatDuration in src/format.js. Accept compact strings made of integer-unit pairs using units d, h, m, s, ms (e.g. "1h30m", "45s", "2d4h", "250ms", "0ms"). Each unit may appear at most once and units must appear in descending order (d, h, m, s, ms); no whitespace, signs, or decimals. Return the total as an integer number of milliseconds. Throw TypeError for non-string input and SyntaxError for malformed input (empty string, unknown unit, out-of-order or repeated unit, missing number, trailing garbage). Add tests in test/parse.test.js covering valid inputs, each invalid category, and a round-trip property parseDuration(formatDuration(n)) === n for a range of values. Mention parseDuration in README.md. Do not change src/format.js behavior.
